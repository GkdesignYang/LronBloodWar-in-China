# 铁血山河 · 中国近代战争与解放战争全史交互舆图 (1931—1958)

> **1931 九一八事变 — 1958 八二三炮战** · 动态疆域分合 · 朱砂虚线残影 · 城池与战役溯源 · 将帅一生行迹 · 舆图盲猜封「大元帅」 · 内置 30FPS 史诗录屏工坊

本项目是一套纯前端、零构建依赖的浏览器交互式中国近代战争与解放战争历史地图应用，汲取古籍羊皮纸设色美学，完整还原从 **1931 年九一八事变** 到 **1958 年金门八二三炮战** 共 **8 大历史时期、20 个关键阶段** 的天下分合与战役推演。

---

## ✨ 六大核心功能

### 1. 拖时间轴，看天下分合 + 「朱砂色虚线残影」
- **20 个关键历史节点**：覆盖九一八事变、中央苏区反围剿、红军长征、遵义会议、西安事变、七七事变、淞沪/太原/徐州/武汉会战、万家岭大捷、百团大战、长沙会战、中国远征军、常德/豫湘桂会战、抗战胜利、中原突围、孟良崮与挺进大别山、辽沈/淮海/平津三大战役、渡江战役、抗美援朝、一江山岛战役至八二三炮战。
- **左下角动态交互图例**：实时展示当前年代各政权、主力部队番号、代表武器装备、兵力规模、战略要塞（旅顺、虎头、江阴等）与海军舰队；鼠标悬停高亮对应疆域或要塞舰队，点击直接平滑聚焦。
- **朱砂色虚线残影**：每切换到一个重大历史节点，上一阶段的边界以朱砂色动态虚线留在地图上，得失进退一目了然。

### 2. 点地溯源 / 战役溯源卡片
- 点击地图上任意历史名城（北京、南京、上海、武汉、长沙、重庆、沈阳、延安、锦州、徐州、台北、金门等）或任意重大战役标记，即弹出 **「1931—1958 全编年溯源卡片」**。
- 详列该城池或战区在各个年代所属政权、最高统帅/守将、重大事件概述与参战兵力规模；**点击卡片内任意一条历史记录，底部时间轴与地图版图立刻跳回当年**。

### 3. 点人溯事：跟着历史人物走完一生行迹
- 内置 **毛泽东、朱德、周恩来、彭德怀、林彪、粟裕、蒋介石、薛岳、孙立人、张学良、山本五十六、东条英机、艾森豪威尔** 等核心人物一生行迹库。
- 地图以动态流光弧线串联人物生平各站，逐站巡礼时，**底部年份、最高统帅、元帅名将、地图版图与右侧人物传记全部同步联动变化**。

### 4. 彩蛋：舆图寻址小试（盲猜落针封「大元帅」）
- 随机抽取 10 道近代重大战役/历史事件线索题，自动隐去地图上所有城池与战役文字标注。
- 在地图上盲猜落针后，按球面大圆真实距离（km）计算偏差并给分，答完 10 题按总分授予军衔，最高荣膺 **「大元帅」**。

### 5. 多功能精准视图缩放与自适应窗口布局
- **初始 100% 全图视野**：启动即完整呈现全部疆域与周边态势，地名标注采用精致比例，放大亦清晰不遮挡。
- **双重缩放控制台**：顶部导航栏与右下角悬浮控制栏均提供 `➕ 放大`、`➖ 缩小`、`60%—600% 无级缩放滑块`、`🗺️ 全图 (100%)` 与 `🎯 核心战区聚焦`。
- **防溢出响应式界面**：任何窗口尺寸下所有菜单、按钮与卡片均严格保持在当前窗口内。

### 6. 内置「🎬 史诗录屏工坊」（一键导出 WebM/MP4 视频）
- 内置 1600×1000 (30FPS) 免权限高清画布合成录屏引擎，支持 **4 种录制模式**：
  1. **🎞️ 录制「时间线演进」**：自动播放选定起止年份的版图分合与战役推演并导出视频。
  2. **👣 录制「指定人物移动路径」**：自动从第 1 站走完最后一站，动态绘制弧线路径与人物生平字幕并保存视频。
  3. **⚔️ 录制「指定战役/事件」推演**：镜头从全图平滑推近聚焦至目标战区，演示动态进军箭矢并导出视频。
  4. **🖐️ 自由操作录制**：实时录制手动拖拽时间轴、缩放与点击操作。
